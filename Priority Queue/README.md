Design and implement a generic priority queue in C++ using templates and the STL list container. The priority queue should support the following operations:

1. Add an item with an associated priority
  -Insert items such that the queue maintains descending priority order (highest priority at the front).
  -If two items have the same priority, preserve the order of insertion (stable ordering).

2. Process (delete) the highest priority item
  -Remove the item with the highest priority from the queue.
  -Display the data and priority of the item being processed.

3. Display all items currently in the queue along with their priorities
  -Show items in order from highest to lowest priority.
