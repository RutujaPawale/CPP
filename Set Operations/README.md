Write a C++ program to perform set operations on student preferences for ice cream flavors.
The program should:

1. Accept the total number of students in a class and store their names.

2. Accept the names of students who like Vanilla.

3. Accept the names of students who like Butterscotch.

4. Find and display:
  -Students who like both Vanilla and Butterscotch.
  -Students who like either Vanilla or Butterscotch or both.
  -The number of students who like neither flavor and their names.
Use unordered_set to store preferences and vector for the universal set.
Display all results clearly.
