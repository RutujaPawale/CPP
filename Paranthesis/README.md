Write a C++ program to check whether a given mathematical expression is well parenthesized or not using the stack data structure.

1. The expression may contain three types of brackets:
  -Round brackets ()
  -Curly braces {}
  -Square brackets []

2. The program should consider the expression valid if:
  -Every opening bracket has a corresponding closing bracket of the same type.
  -Brackets are properly nested.
  -No extra closing or opening brackets remain unmatched.

3. Use the stack container from the C++ Standard Template Library (STL).

4. Read the expression from the user, check validity, and display an appropriate message.
