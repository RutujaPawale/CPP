Write a C++ program to:

1. Convert an arithmetic expression from infix notation to postfix notation using the stack data structure.

2. Evaluate the postfix expression and display the result.

The program should:
  -Read an infix expression (containing operands, operators, and parentheses) from the user.
  -Use a precedence function to determine the priority of operators (+, -, *, /).
  -Correctly handle multi-digit numbers and operator precedence using the Shunting Yard algorithm.
  -Implement a stack-based evaluation of the postfix expression.
  -Handle division by zero with an error message and safe termination.
  =Handle invalid postfix expressions with appropriate error messages.
