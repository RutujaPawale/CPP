Write a C++ program to simulate the operations of a pizza parlor using a circular queue data structure. The pizza parlor can only handle a fixed number of orders at a time. Implement the following functionalities:

1. Place Order – Add a new order to the queue if there is space. If the queue is full, display a message indicating that no more orders can be accepted.

2. Serve Order – Remove the order at the front of the queue (first placed order) and display which order is being served. If there are no orders, display an appropriate message.

3. Display Orders – Show all the current orders in the queue in the order they will be served.

4. Exit – Terminate the program.
