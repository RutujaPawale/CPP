Design and implement a C++ program to perform various operations on binary numbers represented using doubly linked lists. Your program should allow users to:

1. Input two binary numbers and store each bit as a node in a doubly linked list.

2. Display the binary numbers stored in the linked list form.

3. Add the two binary numbers and display the resulting binary number.

4. Compute the 1’s complement of each binary number.

5. Compute the 2’s complement of each binary number.

6. Use appropriate classes and data structures to represent nodes and binary numbers.
