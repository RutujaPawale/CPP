Write a C++ program using function templates to perform Selection Sort on arrays of different data types. The program should:

1. Use a function template so that the same selectionSort function can sort both integer and float arrays.

2. Ask the user to input:
  -The number of integer elements and the elements themselves.

  -The number of float elements and the elements themselves.

3. Perform selection sort separately on the integer array and the float array.

4. Display the sorted arrays after each sort operation.

5. Demonstrate how templates help achieve generic programming in C++.
