Write a C++ program to create a class Student that stores information of students such as:
Name, Class (Standard), Division, Blood group, Contact Address, Driving License number, Date of Birth, Roll Number and Telephone Number.

The class should demonstrate the use of:
Default constructor, Parameterized constructor, Copy constructor, Static data member to maintain the count of the number of student objects, Static member function to access the student count, Dynamic memory allocation using array of objects (using new), Destructor to decrease count when objects are deleted and Input and display functions for student details
Program should display student information in tabular format using setw()

The program should:
  -Ask the user how many students to add.

  -Dynamically create an array of that many student objects.

  -Allow the user to input details for each student.

  -Display all stored student records in a well-formatted table.

  -Print the total number of student objects created.
